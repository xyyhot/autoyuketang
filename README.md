# 雨课堂连续播放助手

## 1.3.0：倍速点击被忽略的根因修复

已从页面公开加载的播放器模块 `27437.3f1750f6.js` 核实：倍速菜单的 mouseover 记录鼠标坐标，mousemove 计算相对距离，click 只有在距离非零时才接受选择并触发网站自己的 setspeed 事件。

旧版合成事件没有坐标，导致移动距离一直为零，点击被忽略。新版从选项位置取坐标，依次发送起点和终点不同的移入、移动事件，再点击选项；后续不再插入会重置起点的 mouseover。仍通过网站原有处理程序设置倍速，不直接赋值视频属性。

14项模拟测试通过，新增回归测试确认旧版零坐标操作被拒绝、新版操作可通过上述移动距离判断。该结果证明事件逻辑修复；新版尚未安装到你的 Edge 实际验证，平台进度入账也尚未验证。

更新时覆盖旧脚本并保存，刷新页面后再开始，避免旧版本仍在页面运行。

## 1.2.0 修正

## 1.1.0 更新

倍速和静音改为点击网站播放器原有控件：选择原生倍速菜单的 `2.00X` 项，点击原生音量图标静音（已经静音时不重复切换）。不再直接修改视频的 `playbackRate`、`muted` 或 `defaultMuted` 属性。设置后检查网站倍速文字和实际媒体状态；失败则暂停提示，不回退到修改属性。

更新方法：在 Tampermonkey 中打开旧脚本，用新版文件全部替换并保存，然后刷新课程页。新版 11 项模拟测试通过，已核对真实页面原生控件 DOM；尚未验证实际安装后的平台进度入账。

适用：Edge + Tampermonkey，以及雨课堂新版 `/ai-workspace/lms-graph/` 学习页。

## 安装

1. 在 Edge 扩展商店搜索并安装 **Tampermonkey**；已安装则跳过。
2. 点击 Tampermonkey 图标，选择“添加新脚本”（或“创建新脚本”）。
3. 用文本编辑器打开同目录的 `yuketang-autoplay.user.js`，复制全部内容，替换新脚本编辑器中的默认模板。
4. 按 `Ctrl+S` 保存，确保脚本已启用。
5. 刷新雨课堂的视频学习页面。右下角应出现“雨课堂连续播放”面板。
6. 如果面板未出现，查看 Tampermonkey 自身的提示，确认脚本运行权限已开启、扩展能访问该站点，并核对页面地址包含 `/ai-workspace/lms-graph/`。

## 使用

手动选择课程及起始视频，点击面板“开始”。脚本会设置二倍速、静音，然后从当前位置向后播放。

- 当前或后续视频有网站完成标记时直接跳过。
- 播放中发现目录完成标记，或当前视频完成度显示 100%，立即暂停并切换到下一个未完成视频，不等视频自然结束。
- 图文、作业、考试、讨论等非视频条目直接跳过，不提交或标记完成。
- 完成状态不明确时按未完成处理；不会返回当前位置之前补播。
- 点击“暂停”会停止当前播放与后续切换。播放器自身暂停也会停止自动运行。
- 同一标签页刷新可恢复运行；换课程需再次点击“开始”。要停止后再刷新，请先点击“暂停”。

请保持页面打开。浏览器后台节流、休眠或系统睡眠可能延迟检测；脚本没有关闭这些机制。正常前台运行时使用 DOM 变化监听即时检测，并每秒补查一次。

## 异常处理

遇到可识别的答题、验证或登录弹窗时停止提醒。无法识别的阻断通常会因播放器暂停或 60 秒无播放进展而停止。处理后点击“开始”。下一节 30 秒未加载也会停止，不反复点击。

切换时必须确认当前目录、页面地址和媒体都发生对应变化。若新播放器暂时仍显示上一段的 100%，先忽略该读数，直到完成度重新更新；目录明确的完成标记仍有效。

## 数据与验证范围

脚本仅操作页面目录与 HTML 视频播放器；无外部依赖、无上传、无学习进度接口调用。运行状态只保存在当前标签页的 sessionStorage。跳过数量是本次页面运行累计数，刷新后归零。

2026-10-22 已对提供的真实课程页面读取并核对：播放器 `video.xt_video_player`、目录 `.leaf-item`、当前项 `.is-active`、类型 `.leaf-item-tag`、完成勾选 `.leaf-item-status .icon-yuanquangou-mianzhuang`、视频完成度 `.rate-detail`。

已通过 11 项模拟 DOM/媒体测试：倍速静音、播放中完成切换、重复触发保护、混合目录跳过、完成图标更新、旧完成度隔离、自然结束、暂停取消切换、手动暂停、刷新恢复与课程隔离、加载超时和卡顿处理（部分场景合并在同一测试中）。

**尚未在 Edge 中安装或运行此脚本，真实连续播放及平台进度记录尚未验证。** 模拟测试不能证明平台将二倍速播放计入完成度。平台是否记入完成以雨课堂自己的显示为准。后续页面结构发生变化时可能需要更新选择器。

## 移除

在 Tampermonkey 管理面板禁用或删除“雨课堂连续播放助手”，再刷新课程页即可。
